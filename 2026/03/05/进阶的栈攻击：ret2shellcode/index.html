进阶的栈攻击：ret2shellcode

什么是 shell

Shell 就是用户和操作系统之间的命令解释器

  • 它读你输入的命令
  • 把命令交给操作系统执行
  • 返回结果给你

常见 shell：

系统 Shell 类型
Linux bash, sh, zsh
Windows cmd.exe, powershell

比如linux中常用的ls cat flag之类的都是shell执行的命令

什么是system

后门函数常见的设置会有system(“/bin/sh”)这段代码，代表调用操作系统去执行你传给它的命令字符串。

这里就是启动一个交互式shell

shellcode 指的是用于完成某个功能的汇编代码，常见的功能主要是获取目标系统的 shell。通常情况下，shellcode 需要我们自行编写，即此时我们需要自行向内存中填充一些可执行的代码

ret2shellcode是指攻击者需要自己将调用shell的机器码（也称shellcode）注入至内存中，随后利用栈溢出复写return_address，进而使程序跳转至shellcode所在内存。

ret2shellcode的核心在于我们需要知道一个地址，在那里写入shellcode才能执行

非常简单的一道题目，读取了我们的输入，然后强行转换类型执行我们的输入，所以直接生成shellcode让系统执行就行
