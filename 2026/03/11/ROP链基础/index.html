ROP链基础

什么是 ROP

ROP = Return Oriented Programming

中文通常翻译为：

面向返回的编程

意思是：

利用程序中已有的代码片段，通过 ret 指令把它们串起来执行，从而完成我们想要的功能。

什么是 Gadget

ROP 的基本单位叫：

gadget

定义：

以 ret 结尾的一小段代码

什么是 ROP 链

ROP chain（ROP 链）：

一系列 gadget 按顺序排列在栈上形成的执行流程

ROP = 用栈控制 ret，让程序现有代码按照攻击者的顺序执行。

一些例子

这是一个32位程序，我们可以看到有一个sh_addr这是因为在rodata段中有字符串其中包含sh这个内容，因此我们在rodata中读取这个字符串作为system的输入参数

至于payload，我们将eip覆盖成system的入口地址之后，需要模拟正常执行system函数的栈环境，对于32位来说，函数传参使用栈传参，所以现在高位写入参数地址，再在低位写入返回地址（复合函数调用的过程：先Push 参数，再push returnaddress）

那么如果没有这种特殊字符串呢？我们可以向bss段（未初始化的全局变量）写入数据，然后再让system函数读取我们写入的/bin/sh就能执行了：

这边对payload进行解释：首先跳转到gets函数，他的参数只有一个，就是需要读入数据的地址，然后返回到system，system的参数是第二个bss_addr 进而就能执行了

由于gets需要我们读入，因此还需要在发送payload后发送一个需要的字符串

那么针对64位程序，由于64位下的函数传参是使用寄存器传参，因此和32位的攻击方式不同：

需要使用gadget：即汇编代码片段

我们可以采用下面的指令进行查找：ROPgadget —binary=./* —only=”pop|ret”进而能够看到类似pop rdi ret这样汇编代码的地址，然后就能利用了：

这个流程就是先返回到pop rdi ret这个代码段的地址

然后将bss的地址放到rdi中，然后ret，ret实际上就是将栈顶的数据放在rip寄存器中，然后栈帧指针向高位移动，也就是说会跳转到gets函数，那么由于rdi中已经放了bss地址，所以就相当于执行gets(bss_addr),执行完毕后继续return到pop_rdi的地址，最后再system

函数调用之后，参数寄存器（如 rdi）通常不会保持原值，因此不能假设 gets 返回后 rdi 仍然是 bss_addr。

所以 ROP 链需要 再次设置一次 rdi。
